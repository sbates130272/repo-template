# Security Policy

## Supported Versions

Use this repository with the latest available versions.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**.

Instead, report it privately via GitHub Security Advisories:

1. Go to **Security** → **Advisories** in the repository
2. Click **New security advisory**
3. Describe the vulnerability and how to reproduce it

Alternatively, contact the maintainers directly through private channels listed in the repository.

## What to Expect

- You will receive a confirmation within 48 hours
- We will work to triage and fix the issue
- We will credit reporters unless they wish to remain anonymous
